`complaints.csv` is generated by `python -m nagrikmitra.generate_data`
(~1,200 rows, seed=42, stratified 70/15/15 by domain). It is committed to
the repo so training is optional on clone (models ship pretrained in
`models/`). `nagrikmitra.db` is created at runtime by `nagrikmitra/store.py`
and is gitignored — never commit it.
